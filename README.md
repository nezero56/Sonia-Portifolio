# Sonia Munezero — Personal Portfolio

A modern, responsive personal portfolio website built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**.

## Features

- Sticky navigation with smooth scroll
- Hero section with profile photo and call-to-action buttons
- About Me with skill tags and CV download
- Expertise cards (Networking, Web Dev, IT Support, Soft Skills)
- Work Experience timeline
- Certifications & Training grid
- Contact form with email, phone, and location details
- Fully responsive mobile layout

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Customization

- **Content**: Edit `src/data/portfolio.ts` to update your info, experience, and certifications
- **Profile photo**: Replace `public/profile.svg` with your own photo (e.g. `profile.jpg`)
- **CV**: Add your CV file as `public/cv.pdf`
- **Colors**: Adjust the primary blue in `src/app/globals.css`

## Tech Stack

- [Next.js 15](https://nextjs.org/) (App Router)
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) (icons)

## Build for Production

```bash
npm run build
npm start
```
